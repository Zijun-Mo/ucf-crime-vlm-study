# Public snapshot and privacy boundary

This repository starts with a clean publication commit. Private local Git history is not included.

Included: scientific Python source and tests, historical workers, fixed experiment protocols,
the portable research website, all 20 accepted prediction conditions (including two E9 ablations), teacher/development
results, statistical analyses, checkpoint hashes and selected small public-dataset illustrations.

Excluded: original videos, model weights, visual feature caches, cloud inventories, Colab
receipts/logs, notebook outputs, local account files, credentials, student identifiers,
messaging exports and original hosting project identifiers.

Private cloud root IDs and quota-project defaults in legacy scripts are replaced by
YOUR_DRIVE_ROOT_FOLDER_ID / YOUR_GOOGLE_QUOTA_PROJECT. The machine-specific Colab
interpreter becomes /opt/colab-cli/bin/python. These are integration placeholders;
provide your own authorized configuration before running cloud orchestration.

Developer annotation evidence paths are replaced by portable filenames. Scientific
scores, time intervals, evaluation rules and statistical results are preserved.
No model inference or training was performed for this publication.

The original archival paths in provenance identify historical inputs; they are not
claims that private operational records or model checkpoints are shipped here.

The original results exporter requires the private archival workspace; the committed
frozen results, standalone CPU verifier and packaging script work without it.
